# CP — Nombres entiers : 3 dessins animés pilotes (paysage + short), 25/11/2026

Pour les petits frères et sœurs de CP (test sur /petits). Ti Margo, ardoise et salle de classe des séries `cp-masse` / `cp-duree` (socle `prototypes/ti-margo`).
Même film en paysage (1920 × 1080, il APPREND) ; un short à part (1080 × 1920, il JOUE).

⭐ Pour des enfants qui ne lisent pas : à l'écran, presque seulement les NOMBRES (en grand) et les dessins. La voix porte le reste.
Chaque nombre dit est écrit. Ceinture blanche partout. L'enfant répond à voix haute ou en montrant du doigt.

État : ⏳ voix à valider par Frédéric (rien n'est enregistré).

## 1. « Combien de fraises ? » — micro `cp_entier_denombre`

### Paysage (≈ 1 min 30)
| Clé | Image | Voix |
|---|---|---|
| 00-accroche | Ti Margo, une assiette de fraises en désordre. Il compte et pointe deux fois la même. | Salut ! Pour le goûter, j'ai des fraises. Combien ? Un, deux, trois, quatre… Oups ! Celle-là, je l'ai déjà comptée ! |
| 01-astuce | Il prend une fraise, la met dans le bol. | Mon astuce : je prends une fraise, je dis un nombre, et je la mets dans le bol. |
| 02-compte | Les fraises sautent une par une dans le bol ; le nombre grandit au-dessus. | Un. Deux. Trois. Quatre. Cinq. Six. Sept. |
| 03-dernier | « 7 » très grand, les 7 fraises s'allument. | Le dernier nombre que je dis, c'est combien il y en a : sept fraises ! |
| 04-question | 5 pommes en désordre. Choix A 4, B 5, C 6. | Question ! Combien de pommes ? Compte avec ton doigt. A : quatre. B : cinq. C : six. Mets pause, et compte ! |
| 04b-reponse | Chaque pomme s'allume avec son nombre. | Réponse B ! Un, deux, trois, quatre, cinq : cinq pommes. |
| 05-question | 7 ballons dans le ciel. Choix A 8, B 6, C 7. | Question ! Combien de ballons ? A : huit. B : six. C : sept. Mets pause, et compte ! |
| 05b-reponse | Chaque ballon s'allume avec son nombre. | Réponse C ! Sept ballons. |
| 06-appris | Titre « Ce que tu as appris », en haut, centré ; un doigt touche les fraises. | Je touche chaque objet une seule fois. Le dernier nombre que je dis, c'est combien. |
| 07-abonne | Écran de fin paysage. | Entraîne-toi sur éleveai point f r. Et si ça t'a aidé : mets un pouce, laisse un commentaire, abonne-toi et active la cloche ! |

| Clé | Image | Voix |

| 01-premier | Le lapin, devant, s'allume ; « 1er » au-dessus. | Celui qui est tout devant, c'est le premier : le lapin. |
| 02-compter | Un doigt avance dans la file : 1er, 2e, 3e. | Après, je compte : premier, deuxième, troisième. Moi, je suis le troisième ! |
| 03-question | Même file. Choix A le chat, B la souris, C le canard. | Question ! Qui est le deuxième ? A : le chat. B : la souris. C : le canard. Mets pause, et montre-le ! |
| 03b-reponse | Le doigt compte 1er, 2e : le chat s'allume. | Réponse A ! Premier, le lapin. Deuxième, le chat. |
| 04-question | Le lapin a glissé. Nouvelle file : chat, Ti Margo, souris, canard. Choix A 3e, B 2e, C 4e. | Question ! Le lapin a glissé. Maintenant, je suis à quelle place ? A : troisième. B : deuxième. C : quatrième. Mets pause, et choisis ! |

## 3. « Une assiette pour chacun » — micro `cp_entier_construire_collection`

### Paysage (≈ 1 min 30)
| Clé | Image | Voix |
|---|---|---|
| 00-accroche | Une fête, des copains arrivent (des animaux : lapin, chat, souris…). | Salut ! C'est la fête ! Mes copains arrivent. Il faut une assiette pour chacun. |
| 01-compter | Il compte les copains. | Combien de copains ? Un, deux, trois, quatre, cinq, six. Six copains. |
| 02-construire | Il pose les assiettes une par une devant chacun. | Je prends six assiettes. Un, deux, trois, quatre, cinq, six. Une assiette pour chaque copain : personne n'est oublié ! |
| 03-question | 5 enfants. Choix A 4, B 5, C 6. | Question ! Il faut un ballon pour chaque enfant. Combien de ballons ? A : quatre. B : cinq. C : six. Mets pause, et choisis ! |
| 03b-reponse | Un ballon arrive dans chaque main. | Réponse B ! Cinq enfants, cinq ballons. |
| 04-question | 4 copains, 3 chapeaux. Choix A oui, B il en manque un, C trop. | Question ! Quatre copains, trois chapeaux. Est-ce qu'il y en a assez ? A : oui. B : non, il en manque un. C : il y en a trop. Mets pause, et choisis ! |
| 04b-reponse | Un copain sans chapeau, tête nue. | Réponse B ! Un copain n'a pas de chapeau. Il en manque un. |
| 05-appris | « Ce que tu as appris ». | Pour en avoir autant, je donne un objet à chacun. |
| 06-abonne | Fin paysage. | (phrase de fin paysage) |
